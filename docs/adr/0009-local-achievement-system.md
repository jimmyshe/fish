# 本地成就系统：独立持久化与主面板成就图鉴

Status: accepted

随着桌面互动、养成与作息机制的丰富，玩家需要一套长期收集与彩蛋探索的目标体系。我们将成就系统设计为**纯本地单机荣誉图鉴**（6 项明示条件与进度的普通成就 + 6 项线索掩码的隐藏彩蛋成就），与联网铲屎排行榜彻底解耦：

1. **纯本地独立持久化**：成就累计进度与解锁时间戳由主进程 `achievementStore` 唯一属主，去抖读写 `userData/achievements.json`（不污染 `config.json`，也不进入云端 `server/` 同步协议），确保未登录单机玩家也能完整体验全部 12 项成就。
2. **纯荣誉徽章图鉴（零锁定）**：初版成就只作为收集荣誉展示，不锁定现有的「物种」或「调色方案」，也不在宠物模型上叠加额外的穿戴配饰图层，保持设置页换肤零门槛与模型组件契约的简洁性（ADR 0008）。
3. **主面板与托盘对称扩展**：主面板（ADR 0005）新增第 3 个 Tab「🏅 成就」，托盘菜单同步增加「🏅 成就」deep-link 入口。
4. **游乐场气泡优先反馈**：解锁瞬间复用小鱼自身的对话气泡（`4000ms` 高优先级，不被同帧动作文案或常规自言自语覆盖；同帧解锁多项自动合并为一条摘要文案）与欢庆粒子（`['🏅', '🎉', '✨', '⭐']`），不在游乐场新增独立 Toast DOM，避免侵入点击穿透命中检测。

## Considered Options

- **上云同步或绑定 PocketID 玩家账号**：需扩展 `server/` SQLite 表结构与同步接口，且未登录用户无法累计单机成就（如本地铲屎、喝水、换肤等），违背「登录可选、不影响单机玩法」原则，否决。
- **成就解锁挂钩隐藏皮肤或头饰配件**：需要在 `species.ts` 与所有 `Model Component` 中维护锁定态或配饰叠加层，初版复杂度高且会限制玩家随心换肤体验，暂不引入。
- **游乐场角落弹出独立 Steam 式 Toast 浮层**：会打破游乐场「仅鱼、屎、气泡」的极简结构（ADR 0005），并增加额外的透明窗口命中检测维护成本，否决。

## Consequences

- `src/shared/achievements.ts` 持有成就定义与纯函数求值器，主进程与渲染进程共享类型与排序/格式化逻辑。
- 主进程新增 `achievementStore.ts`（对标 `poopStore.ts`），在 `will-quit` 时同步落盘，配置/皮肤变更与游乐场事件统一经 `recordAchievementEvents` 求值并广播 `achievements-changed` 与 `achievement-unlocked`。
- 主面板托盘菜单由三项（设置 / 排行榜 / 退出）扩展为四项（设置 / 排行榜 / 成就 / 退出）。
