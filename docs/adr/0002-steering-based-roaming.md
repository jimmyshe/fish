# 漫游 / 避鼠：基于转向力积分的常驻 tick，取代定时跳动

Status: accepted

「自主漂移」原本是每 35~70 秒随机蹦一小步的定时 hop。要实现「在全屏自主游动」和「趋向于逃离鼠标」，hop 模型表达不了两件事：持续的避鼠推离需要一个随距离衰减的力场（事件驱动的 hop 只能在 hop 发生时响应一次），以及速度/朝向的连续性（hop 之间鱼是静止的，谈不上巡航速度和翻转朝向）。因此改为常驻 ~30Hz tick（挂 PetScheduler，命名 `swim-tick`）驱动速度向量积分：每 tick 叠加漫游转向力、边缘软斥力、鼠标回避场，鼠标快速贴近时中断漫游执行一次逃窜冲刺。

## Considered Options

- **定时 hop 加大加频**：改动最小，但避鼠只能"跳一下躲一次"，鼠标缓慢逼近时鱼毫无反应；朝向翻转也不自然。放弃。
- **rAF 驱动积分**：帧率更平滑，但本项目约定"所有定时行为归 PetScheduler 统一属主"（定时器可命名、可取消、卸载自动清理），tick 走 rAF 会脱离这条约定且无法被 scheduler 管理。放弃，选 PetScheduler `every`。
- **力场做进主进程 / 独立 worker**：物理计算量极小（每 tick 几次向量运算），跨进程纯属过度设计。放弃。

## Consequences

- 渲染层出现一个 33ms 的常驻 interval；鱼存活期间 Vue 组件以 ~30Hz 频率重渲染（fishPos 每 tick 变化）。桌面宠物场景下可接受，若将来出现性能问题再考虑把运动状态移出响应式系统、只同步最终 transform。
- 位置持久化时机改为"停靠点"语义：停歇开始、逃窜结束、拖拽结束、beforeunload 各存一次；游动中途不存，断电恢复到上一个停靠点。
- 受惊判定从"鼠标落在 320×200 容器内 + 速度 > 2.5 px/ms"改为"进入贴脸半径（80px）+ 速度 > 2.5 px/ms"：回避场会自然把鱼推离鼠标，旧条件在新模型下几乎永不触发。慢慢靠近只推开不惊吓，快速冲近才触发逃窜。
- 睡眠 / 拖拽 / 设置弹窗期间 tick 照跑但不积分：冻结相位计时，不推进游动。
- 朝向翻转用 `.fish-wrap { scaleX(-1) }`，徽章用独立 `scale: -1 1` 属性反翻转（其 transform 被 pulse 动画完全占用，不能叠加）。
- 运动参数全部硬编码在 `src/renderer/src/lib/fishMotion.ts` 的 `MOTION` 常量；心情联动游速是预留的后续增量，改参数取值即可。
