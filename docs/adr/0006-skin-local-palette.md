# 皮肤：纯本地配色 + renderer 属主注册表，不进同步协议

Status: accepted

鱼的皮肤是具名完整调色板（6 种有效心情 × 身/尾/鳍 = 18 色值），选择以 `skinId` 字符串存 Config（默认 `default`，未知值回退默认皮肤）。调色板注册表归 renderer 属主（`src/renderer/src/lib/skins.ts`）：主进程把 `skinId` 当不透明字符串，只透传持久化、不做校验。皮肤明确不进客户端-服务器同步协议——铲屎事件（Scoop Event）仍是唯一同步内容（ADR 0003 边界不动），服务器无皮肤概念。术语「皮肤」按宽定义（鱼的外观身份）：当前实现是配色皮肤，将来造型皮肤（换 SVG 造型）沿用同一术语与 `skinId` 字段，本决定边界不变。

## Considered Options

- **皮肤同步到服务器（排行榜展示鱼的造型）**：皮肤是单机审美选择，无计数/排行价值；排行榜展示造型需要服务器字段 + 展示面，是独立功能，真做时开新决定，不动本边界。
- **调色板放 `src/shared/`**：主进程没有调色板消费场景，shared 目录定位是类型与契约（config.ts / api.ts）；按「谁消费谁属主」放 renderer lib 层，与纯逻辑 colocated 测试同惯例。
- **基础配色 + 全局心情变换（每皮肤 3 色）**：心情语义被全局锁死，所有皮肤受惊/睡眠的样子都一样；完整 18 色调色板纯查表、零颜色数学逻辑，默认皮肤与现状逐值相等，回归风险最低。
- **心情级 body 色 + tail/fin 派生（每皮肤 6 色）**：需新增 HSL 颜色计算逻辑，且做不出「白身红尾」类定制，表达力受限。
